# Lab J3-M1 — Atelier collaboratif de sécurité intégrée

## Objectif
Animer un atelier entre développeurs, QA, sécurité pour traiter un constat et produire un plan d'action partagé.

## Livrable
- `modeles/fiche-atelier-modele.md` rempli → `fiche-atelier.md`

## Étapes
1. Lire le scénario fourni dans le cours
2. Remplir la fiche atelier (rôles, risques, décisions, actions)
3. Définir un accord de responsabilité avec échéance

## Critère de réussite
Fiche complétée avec au moins 3 actions, chacun avec propriétaire et échéance.
